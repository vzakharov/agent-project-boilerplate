`scripts/run-parallel.sh` runs a set of checks concurrently and reports
only what failed. Each argument is one check — `<label>=<command>` split
at the first `=`, or a bare command that labels itself — so it drives any

buffered per check and printed only for the ones that exited non-zero, a

interpreter beyond the shell, because `scripts/vet.sh` is the one
entrypoint no adopter can decline — `/finalize`, `/sync-branch` and
`/watch-ci` all call it.

their commands. The fan-out form is documented beside its serial examples
