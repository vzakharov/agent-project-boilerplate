```
/sync-branch had exactly one strategy, a plain merge, stated as a hard
invariant. That is the right call once someone has started reviewing —
a rebase rewrites every branch SHA and de-anchors the comments they
anchored to them — but before review starts it charges the first
reviewer, who then reads the branch's work through merge commits it did
not author.

A `pre-review` flag (alias `rebase`) selects a second mode: rebase onto
the freshly-fetched target, then force-push under a lease pinned to the
pre-rebase remote SHA, so origin/<target>..HEAD becomes the branch's own
commits replayed onto the current target and nothing else. The flag is a
token in the argument, order-insensitive against the optional branch
target, matching how /finalize takes `no vet`.

The mode checks its own premise rather than trusting the invocation to
be right about the world. A reviews lookup stops it — overridably, and
by the operator alone — when anyone other than the author has reviewed,
and a shared long-lived branch is refused outright with nothing able to
override that. The existing invariants are scoped per mode rather than
relaxed, so "never rebase" and "never force" keep their full force on
the default path; that scoping is the thing to preserve when editing
this skill, since collapsing it would silently arm the rewrite for every
sync.
```
