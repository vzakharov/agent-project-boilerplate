## Context

The house convention is to write about the agent as **singular they**, not "it".
It first landed in #59, where `CLAUDE.md` § "Language" reads:

> **Agent-facing — English.** … The reader here is the agent: **they** follow

The rest of the tree still has stragglers.

## The boundary is the actual work

The grep is a minute; deciding what *isn't* the agent is the rest of it:

- **A session, a run, a skill, a script or the harness is not an agent.** "A
  session with a life of its own", "the backend re-wakes it", a skill that "finds
  it by heading" — all stay "it". The convention is about the actor, not about
  every noun in the loop's vocabulary.
- **Claude Code the product is a tool** and stays "it".
- **Second person is often the better fix.** The skills already address the agent
  as "you"; where "they" makes a sentence read awkwardly, rewriting to "you" is
  the win, not a workaround.

## Deliberately not in scope: a standing rule

No entry in `CLAUDE.md` or `.claude/rules/` codifying this. The boundary above is
genuinely slippery — a rule stating it would run longer than the sweep and would
misfire on the "it" cases more often than it would help. The bet is that
consistent prose in the tree carries the convention into adopting repos the way
the rest of the loop's voice already does.
